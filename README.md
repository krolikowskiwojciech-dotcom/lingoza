# Lingoza

Rodzinna aplikacja do nauki języków (na razie angielski) w stylu Duolingo: lekcje z powtórkami w odstępach (FSRS),
punkty XP, seria dni, liga rodzinna, odznaki, przypomnienia push i artykuły z klikalnymi słowami.
Nagrania: ElevenLabs (głosy brytyjskie i amerykańskie).

**Aplikacja:** https://krolikowskiwojciech-dotcom.github.io/lingoza/ — na iPhonie otwórz w Safari → Udostępnij → „Do ekranu początkowego”.

- Podstawa metodyczna: [ZASADY-NAUKI.md](ZASADY-NAUKI.md)
- Format treści i narzędzie: [TRESCI.md](TRESCI.md), `node narzedzia/lingoza.mjs`

Biblioteki: [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs) (MIT). Fonty: Jost i Instrument Serif (SIL OFL, `fonts/`).
